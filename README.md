# Platonska-telesa
### Projektna naloga pri predmetu Računalniška orodja v matematiki.

V Mathematici bom narisal vseh pet Platonskih teles. 
Pomagal si bom z razdelkom Cartesian coordinates v https://en.wikipedia.org/wiki/Platonic_solid.

### Načrt projekta
1. Opis platonskih teles,
2. Navedba vseh 5 teles,
3. Uvoz kartezičnih koordinat is spletne strani,
4. vizualizacija teles.
